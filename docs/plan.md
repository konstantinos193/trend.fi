# Product plan

## Vision
Create an on-chain market layer that tracks real-world attention and turns it into tradeable signals.

## Core loop
1. Trend detected and normalized
2. Oracle signs the snapshot
3. Market logic consumes oracle data
4. Users trade and settle

## MVP scope
### Week 1
- Trend ingestion
- Snapshot normalization
- Basic trending feed UI

### Week 2
- Oracle relayer
- Market factory prototype

### Week 3
- Trading UI prototype
- Wallet integration

### Week 4
- Leaderboard
- Shareable activity cards
