# Contributing

Thanks for your interest in TrendFi.

## How to contribute
- Open an issue describing the bug or feature
- Include repro steps or screenshots when relevant
- Keep changes focused and small

## Development
### Frontend
```
cd frontend
yarn install
yarn dev
```

### Supabase
```
cd supabase
supabase start
```

## Pull requests
- Use clear titles and descriptions
- Link issues where possible
- Avoid large refactors in the same PR as feature work
